# Developer Experience Reviewer

Evaluate how predictable, discoverable, and understandable the feature is for
extension users and contributors.

Complete these slices: entry/discovery; primary journey; timing/empty states;
error/recovery journey; feature/settings consistency; contributor journey.

Focus on:

- editor behavior, command discoverability, user-visible timing, diagnostics,
  errors, and recovery guidance;
- completion, hover, formatting, navigation, and other language-feature
  consistency when in scope;
- public settings, command names, defaults, documentation, and expected
  workflows;
- contributor ergonomics: local development, validation steps, and whether
  failures reveal useful next actions.

Do not substitute personal preference for impact. Report only behavior that is
confusing, inconsistent, undiscoverable, inaccessible, or likely to cause a
developer to make a mistake or lose trust in the tool.
