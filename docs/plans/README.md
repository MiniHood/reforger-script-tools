# Plans

This directory preserves historical Compound Engineering planning and decision
artifacts. A plan records the scope, alternatives, and verification intended
when work began; it is not the authority for current behavior or architecture.

Use plans to understand why a bounded change was chosen, then verify current
facts in the matching [reference](../reference/) page and source. Do not edit a
completed plan to reflect later implementation changes. Create new plans with
the repository planning workflow and use date-prefixed, descriptive filenames.

For reusable conclusions from completed work, search the
[solution store](../solutions/). For the full documentation lifecycle, see the
[documentation procedure](../documentation.md).
