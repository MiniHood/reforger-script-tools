# Documentation

This directory is being rebuilt around deep module contracts.

- `architecture/` holds cross-module runtime boundaries and data flow.
- `modules/` holds durable ownership and caller-visible contracts.
- `decisions/` holds consequential design decisions that source cannot explain.
- `evidence/` holds reusable evidence formats and guidance; generated output is
  non-normative.

Do not recreate path-mirrored, per-file current-state documentation. Add a
document only when it explains a stable module boundary, a consequential
decision, or a reusable evidence contract.
