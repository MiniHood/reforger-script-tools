# [Snap And Orient Entities To Terrain Plugin](https://community.bistudio.com/wiki/Arma_Reforger:Snap_And_Orient_Entities_To_Terrain_Plugin)

| Snap and Orient Entities to Terrain |
| --- |
| [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") plugin |
| `Ctrl` + `↡ PgDown` |
| Snaps and orients selected entities to terrain (not "ground" below, terrain only) |
| **File:** [SCR\_SnapAndOrientToTerrainPlugin.c](enfusion://ScriptEditor/scripts/WorkbenchGame/WorldEditor/SCR_SnapAndOrientToTerrainPlugin.c) |

**Snap and Orient Entities to Terrain** is a plugin adding a shortcut to, as its name implies, snap all selected entities to the terrain.

⚠

This plugin snaps entities to the **terrain**, not to any surface or another entity.
To snap to anything below, use World Editor's `Ctrl` + `↓` shortcut (this shortcut does not orient objects to the normal, however).
