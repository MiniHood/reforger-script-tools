## Conflict

This glossary targets the [Conflict](/wiki/Arma_Reforger:Conflict "Arma Reforger:Conflict") game mode and its terminology.

| Name | Meaning | Description/Notes |
| --- | --- | --- |
| Ammunition Supply Point | A military storage facility for live ammunition and explosives. |  |
| Ammunition Truck | Military truck for transporting ammunition. |  |
| Anti-Tank Defense | Defences to prevent the free movements of tanks and similar armoured vehicles. |
| Arsenal Crate | A supply crate containing a Virtual Arsenal. |  |
| Base Management Point | A functional composition where support structures and fortifications can be constructed. |  |
| Building Mode | The in-game mode that allows players to build support structures and fortifications. |  |
| Bunker | A shelter dug into the ground and made strong against attack. |  |
| Checkpoint | A barrier or manned entrance, typically at a border, where security checks are carried out on travellers. |  |
| Command Post | The place from which a unit commander controls a military unit. |  |
| Command Truck | Military truck for transporting a mobile command unit. |  |
| Composition | The nature of something's ingredients or constituents; the way in which a whole or mixture is made up. |  |
| Construction Truck | Military truck for transporting construction supplies. |  |
| Defensive Position | A reinforced defensive position. |  |
| Encampment | A place with temporary accommodation consisting of huts or tents, typically for troops or nomads. |  |
| Field Hospital | a temporary hospital set up to provide emergency medical care for people wounded in military action or affected by a natural disaster or outbreak of infectious disease. |  |
| Fortification | A defensive wall or other reinforcement built to strengthen a place against attack. |  |
| Free Roam Building | The process of using the building mode to build support structures and fortifications. |  |
| Fuel Point | A gas station, fuel supply point, refueling area, or fuel truck. |  |
| Fuel Supply Point | A military storage area for fuel cisterns. |  |
| Fuel Truck | Military truck with a cistern for transporting fuel. |  |
| Heavy Machine-Gun Nest | A machine-gun nest is a fixed position where a machine gun crew sets up their weapon. |  |
| Heavy Vehicle Maintenance Point | A temporary motorpool and repair area for heavy military vehicles. |  |
| Helipad | A landing and take-off area for helicopters. |  |
| Light Vehicle Maintenance Point | A temporary motorpool, refuel and repair area for light military vehicles. |  |
| Living Quarters | Rooms or lodgings, especially those allocated to people in military or domestic service. |  |
| Machine-Gun Nest | A machine-gun nest is a fixed position where a machine gun crew sets up their weapon. |  |
| Medical Area | An abstract zone that acts as a non-physical field hospital in the Game Master mode. |  |
| Medical Point | A field hospital, ambulance, or medical area. |  |
| Mobile Command Unit | The deployable command module transported by a command truck. |  |
| Placement Preview | Semi-opaque projection of a composition, allowing player to preview its orientation and placement. |  |
| Radio Relay Station | A rod, wire, or other device used to transmit or receive radio or television signals; an aerial. |  |
| Repair Point | A vehicle maintenance point, vehicle repair area, or repair truck. |  |
| Repair Truck | Military truck capable of conducting field repairs to other vehicles. |  |
| Squad Management Point | A functional composition where squads can be managed. |  |
| Supply Cache | A stash of weapons and supplies, used by guerrilla forces. |  |
| Supply Depot | A type of military installation used by militaries to store battlefield supplies temporarily on or near the front lines until they can be distributed to military units. Supply depots are responsible for nearly all other types of material, except ammunition. |  |
| Support Item | An inventory item that relates to repairing, refuelling, etc. |  |
| Support Structure | A structure that provides support for combat operations. |  |
| Support Vehicle | A support vehicle that provides support for combat operations. |  |
| Transport Truck | Military truck for transportation. |  |
| Vehicle Maintenance Point | A temporary motorpool and repair area for military vehicles used by guerrilla forces. |  |
| Vehicle Management Point | A functional composition where vehicles can be managed. |  |
| Vehicle Refuel Area | An abstract zone that acts as a non-physical fuel supply point in the Game Master mode. |  |
| Vehicle Repair Area | An abstract zone that acts as a non-physical vehicle maintenance point in the Game Master mode. |  |
