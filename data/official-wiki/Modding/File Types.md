# [File Types](https://community.bistudio.com/wiki/Arma_Reforger:File_Types)

This page lists file types and their respective extensions with which [Arma Reforger](/wiki/Category:Arma_Reforger "Category:Arma Reforger") and the [Workbench](/wiki/Category:Arma_Reforger/Modding/Official_Tools "Category:Arma Reforger/Modding/Official Tools") work.

| Extension | File Type | Saved/Used by | Description |
| --- | --- | --- | --- |
| .acp | Audio component | [Audio Editor](/wiki/Arma_Reforger:Audio_Editor "Arma Reforger:Audio Editor") | Describe audio playback Manages sound events:   * event ("SOUND\_SHOT", "SOUND\_RELOAD" etc) * sound file + parameters (signals, playback rules etc)   Referenced by BaseSoundComponent children |
| .adeb | Animation debug | Animation offline debugger | Binary stream format Contains:   * 16b - File version defined in AnimDebuggerSerializationVersion * List of all debugged descriptors * For each frame list of all debug instances   File can be loaded in animation editor using Live debug tab |
| .ae | Animation Events Table | [Animation Editor](/wiki/Arma_Reforger:Animation_Editor "Arma Reforger:Animation Editor") | Lists all events used in the animation workspace StepEvent, SoundEvent, SynchronizationEvent, etc |
| .afm | Audio Final Mixer | [Audio Editor](/wiki/Arma_Reforger:Audio_Editor "Arma Reforger:Audio Editor") | "Sound mixer" referenced by the [.acp](#.acp) Takes all the sound inputs and produces the final sound output |
| .agf | Animation graph file | [Animation Editor](/wiki/Arma_Reforger:Animation_Editor "Arma Reforger:Animation Editor") | Contains sheets (that contain [Animation Nodes](/wiki/Arma_Reforger:Animation_Editor:_Nodes "Arma Reforger:Animation Editor: Nodes")) of an animation graph |
| .agr | Animation graph | [Animation Editor](/wiki/Arma_Reforger:Animation_Editor "Arma Reforger:Animation Editor") | "root format" sheets collection with graph parameters, e.g commands, variables, IK chains, etc Depends on [.ast](#.ast) |
| .anm | Animation file | [Animation Editor](/wiki/Arma_Reforger:Animation_Editor "Arma Reforger:Animation Editor") + various plugins | Binary animation file |
| .asc | Height map (Esri grid) | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | Height map file which can be exported or imported in Workbench (Terrain tools in World Editor) ⓘ  Not used in runtime neither directly by the editor - only for import/export. |
| .asi | Animation Set Instance | [Animation Editor](/wiki/Arma_Reforger:Animation_Editor "Arma Reforger:Animation Editor") | Bridges [.anm](#.anm) with [.ast](#.ast) abstract names Depends on [.ast](#.ast) See [Animation Editor: Templates and Instances Tutorial](/wiki/Arma_Reforger:Animation_Editor:_Templates_and_Instances_Tutorial "Arma Reforger:Animation Editor: Templates and Instances Tutorial") |
| .ast | Animation Set Template | [Animation Editor](/wiki/Arma_Reforger:Animation_Editor "Arma Reforger:Animation Editor") | Structural skeleton to be filled by [.asi](#.asi) Provides a list of entries to be filled See [Animation Editor: Templates and Instances Tutorial](/wiki/Arma_Reforger:Animation_Editor:_Templates_and_Instances_Tutorial "Arma Reforger:Animation Editor: Templates and Instances Tutorial") |
| .asy | Animation Sync Table | [Animation Editor](/wiki/Arma_Reforger:Animation_Editor "Arma Reforger:Animation Editor") | See [Animation Editor: Sync Tutorial](/wiki/Arma_Reforger:Animation_Editor:_Sync_Tutorial "Arma Reforger:Animation Editor: Sync Tutorial") |
| .aw | Animation Workspace | [Animation Editor](/wiki/Arma_Reforger:Animation_Editor "Arma Reforger:Animation Editor") | [Workbench](/wiki/Category:Arma_Reforger/Modding/Official_Tools "Category:Arma Reforger/Modding/Official Tools")'s Animation Editor "project" - saves/opens current workspace |
| .bt | Behavior tree | [Behavior Editor](/wiki/Arma_Reforger:Behavior_Editor "Arma Reforger:Behavior Editor") | AI behaviour tree |
| .bterr | Terrain data | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | Terrain data - general terrain height map editor information |
| .bttile | Terrain data | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | Terrain data, height-map data for terrain tile used by the editor (original imported height map without modifications by roads etc) |
| .c | Enforce Script Source | [Script Editor](/wiki/Arma_Reforger:Script_Editor "Arma Reforger:Script Editor") | Enforce Script Source file |
| .conf | Generic config | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager")'s [Config Editor](/wiki/Arma_Reforger:Resource_Manager:_Config_Editor "Arma Reforger:Resource Manager: Config Editor") |  |
| .ct | Component Template | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | Defines an Entity Component |
| .dds | Texture | Art Tools | Source image format - other formats are also supported like png, jpeg, tiff, tga, hdr |
| .desc | Terrain dialogs configuration | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | Configuration of terrain texture import/generating dialogs (height map, satellite texture, normal map) |
| .edds | Enfusion DDS Texture | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager")'s [Texture Editor](/wiki/Arma_Reforger:Resource_Manager:_Texture_Editor "Arma Reforger:Resource Manager: Texture Editor") | Enfusion proprietary (extended) compressed DDS texture |
| .emat | Material Definition | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager") | Defines material for 3D objects, terrain, post processes, water, sky objects etc |
| .ent | World Scene | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | World contains terrain and all other objects that make up the your game world |
| .et | Entity Template | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | Defines an Entity content (prefab) |
| .fbx | 3D model source file | 3D software | [.txo](#.txo) and [.xob](#.xob) source format |
| .fnt | Font | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager")'s [Font Viewer](/wiki?title=Arma_Reforger:Resource_Manager:_Font_Viewer&action=edit&redlink=1 "Arma Reforger:Resource Manager: Font Viewer (page does not exist)") | Font for UI widget system, binary format |
| .gamemat | Game material | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager")'s [Config Editor](/wiki/Arma_Reforger:Resource_Manager:_Config_Editor "Arma Reforger:Resource Manager: Config Editor") | Definition of in-game material (properties, sound, etc) |
| .gproj | Project-specific Settings | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | Every Project has its own settings stored here |
| .imageset | ImageSet Definition | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager")'s [Imageset Editor](/wiki/Arma_Reforger:Resource_Manager:_Imageset_Editor "Arma Reforger:Resource Manager: Imageset Editor") | Defines a set of images by cuts from a texture |
| .layer | World Layer | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | World file (.ent) can have mutliple layers stored in separate .layer files - can only be opened through the [.ent](#.ent) file |
| .layout | Layout Definition | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager")'s [Layout Editor](/wiki/Arma_Reforger:Resource_Manager:_Layout_Editor "Arma Reforger:Resource Manager: Layout Editor") | UI layout definition |
| .meta | Meta Information | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager") | Every registered asset has its meta file containing asset-specific settings and asset GUID |
| .nmn | Navmesh | Navmesh Generator Tool | Binary file with single navmesh instance - see [Navmesh Tutorial](/wiki/Arma_Reforger:Navmesh_Tutorial "Arma Reforger:Navmesh Tutorial") |
| .pak | Package (of data) | [Workbench](/wiki/Category:Arma_Reforger/Modding/Official_Tools "Category:Arma Reforger/Modding/Official Tools") | Game or Mod data archive |
| .pap | PA project | [Procedural Animation Editor](/wiki/Arma_Reforger:Procedural_Animation_Editor "Arma Reforger:Procedural Animation Editor") | See [Procedural Animation Editor](/wiki/Arma_Reforger:Procedural_Animation_Editor "Arma Reforger:Procedural Animation Editor") |
| .physmat | Physics material | [Config Editor](/wiki/Arma_Reforger:Resource_Manager:_Config_Editor "Arma Reforger:Resource Manager: Config Editor") | Physical material (bounciness, adherence etc) |
| .pre | ResourceViewer Preset | Resource Browser | A preset with several options to allow customisation of Workbench's preview windows (usually saved in %userprofile%\Documents\My Games\ArmaReforgerWorkbench\profile\ResourceViewerPresets) |
| .ptc | Particle System Definition | [Particle Editor](/wiki/Arma_Reforger:Particle_Editor "Arma Reforger:Particle Editor") | Particle effects definition |
| .ragdoll | Ragdoll Definition | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager") | Character ragdoll file |
| .rdb | Resource Database | [Workbench](/wiki/Category:Arma_Reforger/Modding/Official_Tools "Category:Arma Reforger/Modding/Official Tools") | Resource database listing all resources in the project |
| .sig | Signal | [Audio Editor](/wiki/Arma_Reforger:Audio_Editor "Arma Reforger:Audio Editor") | Describes the logic of playing an audio component or encapsulate manipulation parameters - this audio resource is shared among audio components |
| .siga | PA signal | [Procedural Animation Editor](/wiki/Arma_Reforger:Procedural_Animation_Editor "Arma Reforger:Procedural Animation Editor") | Describes the control logic for parts of a PA project - this resource is shared among PA projects |
| .smap | Soundmap data | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | Information for music and audio effects |
| .snd | Sound container | [Audio Editor](/wiki/Arma_Reforger:Audio_Editor "Arma Reforger:Audio Editor") | [armareforger-symbol black.png](/wiki/Category:Arma_Reforger/Version_1.6.0 "Category:Arma Reforger/Version 1.6.0") [1.6.0](/wiki?title=Category:Arma_Reforger/Version_1.6.0&action=edit&redlink=1 "Category:Arma Reforger/Version 1.6.0 (page does not exist)") A wrapper for [.wav](#.wav) and [Opus](https://en.wikipedia.org/wiki/Opus_(audio_format)) .ogg files |
| .st | String Table | [String Editor](/wiki/Arma_Reforger:String_Editor "Arma Reforger:String Editor") | Strings used for localisation |
| .stars | Database | Proprietary format | Runtime database of stars. Contains up to 100.000 stars describing their real positions and colors  Array of Hunks (ID = "ITEM") each Hunk describes a Star object with following data:   * Ra - Right ascension (float) * Dec - Declination (float) * ProMoRa - Proper motion in right ascension (float) * Parallax - (float) * Magnitude - Star brightness (float) * Color - Star color (uint32 RGBA) * HIP Catalog - Dummy (not used uint32) * Name - Star name, with max. 256 characters length   [Source data](https://cdsarc.cds.unistra.fr/viz-bin/Cat?I/311) |
| .styles | Widget Style Definition | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager")'s [Styles Editor](/wiki?title=Arma_Reforger:Resource_Manager:_Styles_Editor&action=edit&redlink=1 "Arma Reforger:Resource Manager: Styles Editor (page does not exist)") | Defines UI style |
| .terr | Terrain data | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | Terrain height map information |
| .topo | Topography data | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | Information for 2D map |
| .ttf | TrueType Font | Resource Browser | Source font file format supported by Enfusion |
| .ttile | Terrain data | [World Editor](/wiki/Arma_Reforger:World_Editor "Arma Reforger:World Editor") | Terrain data, height-map data for terrain tile used in run time (here are baked modifications by roads etc) |
| .txa | Animation file | [Animation Editor](/wiki/Arma_Reforger:Animation_Editor "Arma Reforger:Animation Editor") | Text animation file (source for [.anm](#.anm)) - source animation |
| .txo | Model | Resource Browser + various plugins (see [Enfusion Blender Tools](/wiki/Arma_Reforger:Enfusion_Blender_Tools "Arma Reforger:Enfusion Blender Tools")) | Text model file (source for [.xob](#.xob)) - source model |
| .vhcsurf | Vehicle surface | [Config Editor](/wiki/Arma_Reforger:Resource_Manager:_Config_Editor "Arma Reforger:Resource Manager: Config Editor") | Surface properties that are used inside vehicle simulation (roughness, steering noise etc.) |
| .wav | Supported audio file format | Audio software | WAV file format |
| .xob | Model | Resource Browser | Binary model file |
