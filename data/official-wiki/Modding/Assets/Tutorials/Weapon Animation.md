# [Weapon Animation](https://community.bistudio.com/wiki/Arma_Reforger:Weapon_Animation)

This tutorial assumes that the weapon has some basic skinning and configuration. Instructions for those can be found on the [Weapon Creation](/wiki/Arma_Reforger:Weapon_Creation "Arma Reforger:Weapon Creation") page.

Beside that, it is also expected that at least **Blender 3.6 LTS** is installed together with the latest version of the [Enfusion Blender Tools](/wiki/Arma_Reforger:Enfusion_Blender_Tools#Export_TXA_Enfusion_Blender_Tools_plugin "Arma Reforger:Enfusion Blender Tools").

The Weapon animation tutorial is divided into 3 parts:

* [Setup](/wiki/Arma_Reforger:Weapon_Animation/Setup "Arma Reforger:Weapon Animation/Setup") - in this part you will get familiar with the [Animation Editor](/wiki/Arma_Reforger:Animation_Editor "Arma Reforger:Animation Editor"), preparing new animation workspace for weapon by duplicating some existing files and linking this new workspace to the weapon prefab
* [Basic Tutorial](/wiki/Arma_Reforger:Weapon_Animation/Basic_Tutorial "Arma Reforger:Weapon Animation/Basic Tutorial") - this page covers actual creation of animations in **Blender** and their export to Workbench, preparation of weapon IK pose and some basic weapon animation
* [Advanced Tutorial](/wiki/Arma_Reforger:Weapon_Animation/Advanced_Tutorial "Arma Reforger:Weapon Animation/Advanced Tutorial") - this part describes process of creating more complex animations - additive motion, creation of prone variants of weapon animations, retargeting animations using Reforger source data and more
