# [From Arma 3 Tools to Workbench](https://community.bistudio.com/wiki/Arma_Reforger:From_Arma_3_Tools_to_Workbench)

Arma 3 Tools Launcher

This page offers an equivalence table between Arma 3 Tools and Workbench, the new Enfusion Tools suite.

Equivalences are not always possible nor entirely accurate, as some functionalities do not have a perfect match, if any.

| [BinMake](/wiki/BinMake "BinMake") | Addon binarisation | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager"): Pack Project |
| [CfgConvert](/wiki/CfgConvert "CfgConvert") | Config binarisation | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager"): Pack Project |
| [Sound Tools](/wiki/Sound_Tools "Sound Tools") | Audio file conversion | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager"): Import (audio) |
| [ImageToPAA](/wiki/ImageToPAA "ImageToPAA") | Image file conversion | [Resource Manager](/wiki/Arma_Reforger:Resource_Manager "Arma Reforger:Resource Manager"): Import (image) |
